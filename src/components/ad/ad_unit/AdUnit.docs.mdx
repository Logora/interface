---
description: An ad unit component that displays an ad slot with Google Ad Manager
labels: ['ad', 'google-ad-manager']
---

The AdUnit component displays an ad slot from Google Ad Manager.

It also handles the ads refresh of its own slot and the configuration to respect the user's cookie consent.
Consent is managed with didomi and is optional.

The slot is declared with the `origine=logora` targeting and refreshed only when it becomes viewable itself: the other slots of the page (including the publisher's own ad slots) are never refreshed nor reconfigured by the component.

### Component usage

```js
    import { AdUnit } from '@logora/debate.ad.ad_unit';
```

```js
<AdUnit
    id='div-id' 
    adPath='/path'
    sizes={[300, 250]}
/>
```

### Properties
| **Name** | **Type** | **Required** | **Default** | **Description** |
| ----------- | ----------- | :-----------: | ----------- | ----------- |
| <font color='#4646c6'>refreshRate</font> | <font color="#397300">integer</font> | &cross; | 8000 | <font color="grey">*Delay in milliseconds before refreshing the slot once it is viewable, 0 to disable the refresh*</font> |
