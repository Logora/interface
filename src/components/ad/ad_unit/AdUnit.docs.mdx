---
description: An ad unit component that displays an ad slot with Google Ad Manager
labels: ['ad', 'google-ad-manager']
---

The AdUnit component displays an ad slot from Google Ad Manager.

The component owns its slot end to end: it defines the slot, displays it once,
destroys it on unmount and never touches slots owned by the publisher. Refresh
is opt-in (`refresh`) and only ever targets its own slot, at most every 30
seconds and only after a viewable impression while the tab is visible. When the
delay expires while the tab is hidden, the refresh is deferred and the timer
restarts when the tab becomes visible again. When the page disabled initial
load, the slot is refreshed once right after display so it is never left
empty — even with `refresh` set to `false`.

It also handles the per-slot refresh and the configuration to respect the user's cookie consent.
Consent is managed with didomi and is optional.

### Component usage

```js
    import { AdUnit } from '@logora/debate.ad.ad_unit';
```

```js
<AdUnit
    id='div-id'
    adPath='/path'
    sizes={[300, 250]}
/>
```
