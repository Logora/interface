A hook that inserts the script from Google Ad Manager (GPT).

The hook only loads `gpt.js` once per page. It never calls page-wide `pubads`
settings (`enableSingleRequest`, `disableInitialLoad`, `collapseEmptyDivs`) and
never refreshes ad slots, so it cannot interfere with ad slots owned by the
publisher. Slot lifecycle (`defineSlot`, `display`, `refresh`, `destroySlots`)
belongs to `AdUnit`.

When the page already loads `gpt.js`, the hook neither injects the script nor
calls `enableServices()`: the publisher snippet keeps full control of the page
configuration. When the hook does load `gpt.js` itself, it calls
`enableServices()` once — GPT ignores page-level `pubads` settings applied after
that call, so a page that configures GPT itself must ship its own GPT snippet
instead of relying on the hook.

The hook can also add consent attributes from [didomi](https://www.didomi.io/fr/) to manage user consent.

### Component usage

```js
import { useGoogleAdManager } from '@logora/debate.ad.use_google_ad_manager';

function MyComponentWithGPT() {
  useGoogleAdManager();

  return <div id="my-root">Hello World</div>;
}
```

| **Name**      | **Type** | **Required** | **Default** | **Description** |
| ----------- | ----------- | :-----------: | ----------- | ----------- |
| <font color='#4646c6'>enable</font> | <font color="#397300">boolean</font> | &cross; | true | <font color="grey">*Whether to insert the script*</font> |
