A modal asking a non-subscriber to subscribe before participating in a subscribers-only module.

### Component usage
```js
import { SubscriptionModal } from '@logora/debate.auth.subscription_modal';

<ConfigProvider config={config}>
<ModalProvider>
    <IntlProvider locale="en">
        <SubscriptionModal
            title="Subscribe to comment"
            text="Commenting is reserved to subscribers."
            buttonLabel="Subscribe"
            url="https://example.com/subscribe"
        />
    </IntlProvider>
</ModalProvider>
</ConfigProvider>
```

### Props

| Prop | Description | Default |
|---|---|---|
| `title` | Modal title | `auth.subscription_modal.title` translation |
| `text` | Body text | `auth.subscription_modal.text` translation |
| `buttonLabel` | Subscribe button label | `auth.subscription_modal.button` translation |
| `url` | Subscription page URL, opened in a new tab | none |
| `onLogin` | When set, shows an « Already have an account ? Sign in » link calling it | none |

Without `url`, no button is displayed. The layout matches the SSO login modal: the client logo (`config.logo_url`, or a default icon), a bold title, the text and the button.

`useAuthRequired` shows this modal with `config[module].subscriptionModal` when the module sets `subscribersOnly: true` and the current user is not a subscriber. For visitors it also passes `onLogin`, which opens the login flow.
